# Arch Linux Installer 0.1.0

Русскоязычный установщик Arch Linux: UEFI/GPT, Ext4, GRUB, KDE Plasma 6, CachyOS BORE, проприетарный NVIDIA 580xx DKMS, Wine, ZRAM, Firefox и Яндекс Браузер.

## Целевая система

- AMD Ryzen 7 5700X (Zen 3 / x86-64-v3), NVIDIA RTX 2060 6 GB, 64 GiB RAM.
- `linux-cachyos-bore` и headers; стандартное ядро Arch остаётся резервным.
- Проприетарный `nvidia-580xx-dkms` для RTX 2060/Turing, включая 32-битные библиотеки для Wine.
- KDE Plasma 6, SDDM, Wayland + X11.
- `ru_RU.UTF-8`, раскладки `us,ru`, переключение Alt+Shift.
- Нативный Wine + Winetricks; 32-битные Vulkan/ALSA/PulseAudio библиотеки.
- ZRAM: `min(ram / 2, 16384)` MiB, Zstd.
- Firefox, `yandex-browser` из AUR, Flatpak + Flathub, KDE Discover.

## Запуск из Arch Linux ISO

Загрузить ISO именно в UEFI, подключить интернет, проверить дату/время:

```bash
curl -fsSL https://raw.githubusercontent.com/USERNAME/arch-linux-installer/main/install.sh -o install.sh
chmod +x install.sh
./install.sh --dry-run
./install.sh
```

`USERNAME` заменить на имя GitHub-аккаунта после создания репозитория.

## Разметка

- GPT.
- EFI System Partition: 1 GiB FAT32, точка монтирования `/boot`.
- Остальное пространство: Ext4, корень `/`.
- Отдельного `/home` и swap-раздела нет; swap обеспечивается ZRAM.

## Защита

Установщик требует выбрать диск по номеру, показывает `lsblk` и требует ввести точное подтверждение `ERASE /dev/...`. Затем запрашивает ещё одно подтверждение. Выбранный диск полностью очищается. Перед подтверждением обязательно сверить модель, размер и разделы.

Пароли не передаются в аргументах процессов: временный файл создаётся в целевой системе с правами 0600 и удаляется в начале настройки chroot.

## Технические замечания

- Скрипт предназначен для запуска из Arch Linux ISO, загруженной в UEFI. Legacy BIOS не поддерживается.
- Secure Boot в этой версии должен быть отключён.
- BORE kernel берётся из официального репозитория CachyOS через их штатный `cachyos-repo.sh`. После настройки возвращается `core/pacman` из Arch и удаляется секция `[cachyos]`, оставляя v3 репозитории для BORE.
- NVIDIA 580xx DKMS и Яндекс Браузер собираются/устанавливаются через AUR. AUR — пользовательский репозиторий, не официальный репозиторий Arch. PKGBUILD следует проверять.
- Пакет Яндекс Браузера в AUR поддерживается сообществом, не самим Яндексом.
- Установка AUR-пакетов может занять время. Если текущая версия BORE и NVIDIA 580xx несовместимы, установка остановится; обычное ядро Arch останется как резерв.
- Для VMware создать отдельную UEFI VM с виртуальным диском 60 GiB или больше. Не передавать установщику физические диски основного компьютера.
- Это прототип 0.1.0. До запуска на основном ПК сначала полностью проверить установку в VMware и проверить журнал `/var/log/arch-linux-installer/`.

## Проверка

`./install.sh --dry-run` проверяет среду и не меняет диски. Обычный запуск — разрушительный для выбранного диска.
